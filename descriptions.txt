======================================================================
BUG DESCRIPTIONS FOR TASK SUBMISSIONS (PIXELFORGE)
======================================================================
Use these short, precise descriptions when submitting the tasks on the platform.
They are under 80 words, name the bug class, file, function, and triggering condition, and do NOT reveal the fix.
----------------------------------------------------------------------

BUG 1 (Heap Use-After-Free)
---------------------------
"A heap-use-after-free occurs in PixelForge::BMPCodec::Decode in src/bmp_codec.cc. The vulnerability is triggered by decoding a BMP file with a specific resolution value (biXPelsPerMeter), caching a raw pointer to its pixel buffer, destroying the decoded image, and subsequently decoding a second BMP file that triggers a compositing operation using the cached dangling pointer."

BUG 2 (Heap Buffer Overflow / Out-of-Bounds Write)
--------------------------------------------------
"A heap-buffer-overflow occurs in PixelForge::GIFCodec::Decode in src/gif_codec.cc during LZW decompression. The overflow is triggered when decoding LZW bitstreams containing code values that exceed the current dictionary boundaries."

BUG 3 (Use-After-Free)
----------------------
"A heap-use-after-free occurs in PixelForge::FilterPipeline::GetImage in src/filter.cc. The vulnerability is triggered by retrieving a cache-evicted image pointer from the filter cache and subsequently applying image filters to it."

BUG 4 (Double Free)
-------------------
"A heap-double-free occurs in PixelForge::FilterPipeline::ClearCache in src/filter.cc. The crash is triggered by evicting an image from the filter cache to trigger initial freeing, followed by clearing the cache to free the same pointer again."

BUG 5 (Heap Buffer Overread)
----------------------------
"A heap-buffer-overflow read occurs in PixelForge::TGACodec::Decode in src/tga_codec.cc. The overread is triggered when decoding a run-length encoded (RLE) TGA file containing packet run counts that exceed the available input stream bytes."

BUG 6 (Type Confusion)
----------------------
"A type confusion crash occurs in PixelForge::MetadataParser::ViewExif in src/metadata.cc. The crash is triggered when casting a comment metadata block to an EXIF metadata block and attempting to read its properties."
